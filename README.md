# Working Calculator Website

Responsive calculator built with plain HTML, CSS, and JavaScript.

## Run
Open `index.html` in a web browser. No installation or build step required.

## Features
- Digits 0–9
- Addition, subtraction, multiplication, division
- CE reset and equals
- Keyboard support: digits, +, -, *, /, Enter or =, Escape/Backspace
- Division-by-zero handling

## Publish with GitHub Pages
1. Create a GitHub repository named `calculator-website`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
5. Use the Pages URL shown by GitHub after deployment.
